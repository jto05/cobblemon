# Cobblemon + Create Modpack

Minecraft 1.21.1 · NeoForge · updates itself every launch.

## Install

1. Install **[Prism Launcher](https://prismlauncher.org/download)** and sign in with your Microsoft account.
2. Download the `.zip` from the **[Releases page](https://github.com/jto05/cobblemon/releases)**. Don't unzip it.
3. In Prism: **Add Instance → Import**, pick the zip, click **OK**.
4. Press **Play**. The first launch downloads the mods and takes a few minutes. Let it finish.
5. Join the server from **Multiplayer**. Ask the server owner for the address and to whitelist your Minecraft username.

## Tips

- 16 GB of RAM is recommended. If the game runs out of memory, raise it in **Edit → Settings → Java**.
- The server is on a home connection. Join one at a time, and wait a minute before retrying if you get disconnected.
